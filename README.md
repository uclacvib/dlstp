# dlstp

+ Training environment and scripts are provided in `models/{3duxnet,nnUnet,umamba,unetr}/docker` folder.

+ Sample training entry point and input files are provied in `models/{3duxnet,nnUnet,umamba,unetr}/condor` folder.

+ Prebuilt containers can be access via [docker hub](https://hub.docker.com/repository/docker/pangyuteng/dlstp), container url and tag are provided below for the available models.

```
pangyuteng/dlstp:3duxnet-v0.0.1
pangyuteng/dlstp:nnunet-v0.0.1
pangyuteng/dlstp:umamba-v0.0.1
pangyuteng/dlstp:unetr-v0.0.1
```
